  Bespoke name:   ea-niti-core-1.1b-q4
  Base model:     repro/repro-mini-1.1b (Q4_0 GGUF quantization)
  Base URL:       https://huggingface.co/repro/repro-mini-1.1b-gguf
  Base licence:   Apache License 2.0
  Mods:           Renamed; metadata stamped with EA-NITI provenance.
                  No fine-tuning, no weight edits, no distillation.
  Source of
  truth:          public/models/ea-niti-core-1.1b-q4.meta.json

  The bespoke file is tracked via Git LFS (see `.gitattributes`).

  `EA_NITI_BASE_MODEL_URL` before running
  `node scripts/forge_bespoke_model.mjs`.
